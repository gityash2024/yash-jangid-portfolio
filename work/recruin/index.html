The challenge

Many actors. One coherent workflow.

Recruiting products connect multiple user types and states: profiles, jobs, applications, conversations, access control and tracking. The challenge is making those moving parts feel like one product instead of a collection of unrelated screens.

Engineering work

Product flows backed by reliable state.

  • Built React and Node.js product workflows with MongoDB persistence.
  • Implemented matching and applicant-tracking flows for recruiters and candidates.
  • Supported real-time chat and secure JWT-based access control.
  • Worked with AWS S3 for asset/file workflows.
  • Contributed to a live platform serving 5,000+ active users.
What it taught me

Scale is also a UX problem.

Systems become difficult not only when traffic grows, but when workflow states multiply. Good product engineering means making backend state, permission boundaries and user intent line up cleanly.
