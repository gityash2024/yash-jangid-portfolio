CEX / DEX Strategy
Portal.

A low-latency trading platform built around synchronized market data, exchange/order workflows, Redis caching and WebSocket-driven updates.

DomainTrading / Web3

The challenge

Fresh data under pressure.

Trading systems are unforgiving: stale data, slow APIs or inconsistent exchange state can immediately degrade the product. The platform needed to coordinate high-volume API traffic and real-time market updates while keeping user-facing workflows responsive.

Engineering work

Design around the hot path.

  • Built real-time WebSocket workflows for synchronized market and order updates.
  • Used Redis caching to reduce repeated work and improve server response times.
  • Designed APIs and service boundaries around high-throughput trading workflows.
  • Contributed to architecture capable of handling 10,000+ API requests per minute.
  • Worked on sub-100ms response paths where latency materially affected experience.
Outcome

Performance that users can feel.

The broader platform work contributed to a 40% reduction in server latency and strengthened the engineering practices around real-time systems, reusable components and production delivery.
