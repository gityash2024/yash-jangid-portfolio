01 · The challenge

Many systems. One clinical workflow.

Medical imaging software is not just a viewer. Data has to arrive, be categorized, move through processing, remain traceable, become available to visualization, and connect to AI-assisted analysis without hiding what the pipeline is doing.

The engineering challenge is building a product layer around those moving parts while keeping state understandable for the people operating the workflow.

STATE

Make pipeline state visible

Users need to know what arrived, what is running, what failed and what output exists.

BOUNDARIES

Keep services decoupled

Viewer, storage, orchestration and AI execution should evolve without turning into one tightly coupled block.

PRODUCT

Translate complexity into action

Technical state only matters if the interface makes the next useful action obvious.

02 · What I’m building

From ingestion to AI-assisted analysis.

  • DICOM/NIfTI ingestion, processing and pipeline-management workflows.
  • OHIF Viewer integration for medical-image visualization.
  • Orthanc integration for imaging data management and workflow coordination.
  • Backend APIs and orchestration services for structured processing.
  • LLM/AI workflow execution and AI-assisted imaging analysis.
  • Frontend workflows that connect processing state to clear user actions.
03 · Engineering lens

Orchestration is a product problem.

For a system like this, architecture and UX are tightly connected. A technically correct backend is not enough if the interface cannot explain progress, failure or output. I treat orchestration state, observability and interface design as one connected problem.

The same principle applies to AI: the model should sit inside a controlled workflow with explicit inputs, tools, state and outputs rather than behave like an opaque feature bolted onto the side.

What this work demonstrates

Full-stack ownership across a high-context domain.

The value is in connecting specialized healthcare tooling with product-grade orchestration, interfaces and backend systems.
